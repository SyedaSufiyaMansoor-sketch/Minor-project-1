# 🧬 Groups DNA

## 📌 About the Project

**Groups DNA** is a simple Python-based mini project that analyzes the activity of members in a WhatsApp group.

The project helps identify interesting group characteristics such as:

* 👻 Who is the **Ghost** (least active member)
* 🔥 Who is the **Most Active** member
* 😴 Who is **Less Active**
* 💬 Who sends the **Most Messages**
* 😂 Who is the **Meme/Gossip King or Queen**
* 📊 Overall group activity

## 🎯 Objective

The main objective of this project is to analyze WhatsApp group chat data and understand the behavior and activity of different group members.

## 🛠️ Technologies Used

* Python
* Pandas
* Basic Data Analysis

## ⚙️ How It Works

1. Provide WhatsApp group chat data.
2. The program processes the messages.
3. It counts messages sent by each member.
4. It compares member activity.
5. It displays the results and identifies different group roles.
